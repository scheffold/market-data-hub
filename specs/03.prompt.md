# Kubernetes Deployment + Docker Registry + MCP Server Implementation

**Feature Branch:** feature/k8s-deployment-docker-mcp

## Objective
Establish production-ready Kubernetes deployment with automated Docker image building/pushing to GitHub Container Registry, add MCP (Model Context Protocol) server functionality with SSE transport alongside FastAPI HTTP API, and document the complete deployment pipeline.

## Core Requirements

### 1. Kubernetes Deployment Architecture (Dev + Production)

**Deployment Structure:**
- Development (Minikube/Kind): Single replica, minimal resources (0.5 CPU, 512Mi memory), no load balancer
- Production-ready template for easy scaling (2-3 replicas, 1 CPU, 1Gi memory)
- Mount IBKR_HOST from ConfigMap (external connectivity)
- Mount secrets from Kubernetes Secret (credentials)
- Health checks: startup probe (30s), liveness probe (10s), readiness probe (5s)

**Files to Create/Update:**
- `k8s/deployment.yaml` - Main deployment with resource limits, environment injection, secret references
- `k8s/service.yaml` - Service with NodePort for Minikube, LoadBalancer for production
- `k8s/configmap.yaml` - ConfigMap for non-sensitive config (IBKR_HOST, IBKR_PORT, IBKR_MARKET_DATA_TYPE)
- `k8s/secret-template.yaml` - Template showing how to create secrets (never commit actual values)

### 2. GitHub Actions CI/CD Pipeline

**Workflow Enhancement:**
- Modify existing `.github/workflows/ci.yml` to include Docker build and push steps
- Update IMAGE_NAME from `jfrog-cve-dashboard` to `market-data-hub`
- Add GitHub Container Registry authentication
- Build on all tags and main branch push
- Push to `ghcr.io/${{ github.repository }}:latest` and `ghcr.io/${{ github.repository }}:${{ github.sha }}`

**Updated CI Workflow:**
```yaml
name: CI/CD

on:
  push:
    branches: ["main", "develop"]
    tags: ["v*"]
  pull_request:
    branches: ["main", "develop"]

env:
  PYTHON_VERSION: "3.12"
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}

jobs:
  quality:
    name: Lint and Test
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt
          pip install ruff pytest

      - name: Lint
        run: ruff check .

      - name: Run tests
        run: pytest --maxfail=1 --disable-warnings

  build-and-push:
    name: Build and Push Docker Image
    runs-on: ubuntu-latest
    needs: quality
    permissions:
      contents: read
      packages: write
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Log in to Container Registry
        uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Extract metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}
          tags: |
            type=ref,event=branch
            type=semver,pattern={{version}}
            type=semver,pattern={{major}}.{{minor}}
            type=sha

      - name: Build and push
        uses: docker/build-push-action@v5
        with:
          context: .
          push: ${{ github.event_name != 'pull_request' }}
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=registry,ref=${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:buildcache
          cache-to: type=registry,ref=${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:buildcache,mode=max
```

### 3. MCP Server Integration with SSE Transport

**Architecture:**
- Unified entrypoint: `app/main.py` accepts `--mode` CLI argument
- Default mode: `http` (FastAPI HTTP server on port 8000)
- MCP mode: `mcp` (FastMCP SSE server on port 8001)
- Both modes expose the same FastAPI app, just different transport protocols

**New Files:**
- `app/mcp.py` - MCP server initialization and configuration
- Update `app/main.py` - Add CLI argument parsing for mode selection
- Update `pyproject.toml` - Add `fastmcp` dependency

**Implementation: `app/mcp.py`**
```python
"""MCP (Model Context Protocol) server implementation."""

from fastmcp import FastMCP
from fastapi import FastAPI
import logging

logger = logging.getLogger(__name__)


def create_mcp_server(app: FastAPI) -> FastMCP:
    """
    Create MCP server from FastAPI application.

    Uses SSE (Server-Sent Events) transport for remote client access.
    Exposes all FastAPI endpoints as MCP resources.

    Args:
        app: FastAPI application instance

    Returns:
        FastMCP server instance ready to run
    """
    mcp = FastMCP.from_fastapi(app=app)

    logger.info("MCP server created with SSE transport")
    return mcp
```

**Implementation: Updated `app/main.py`**
```python
"""Market Data Hub - FastAPI with MCP support."""

import asyncio
import logging
import sys
from contextlib import asynccontextmanager
from typing import Optional

import uvicorn
from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse

from app.api import routes_meta, routes_prices, routes_companies, routes_options, routes_ws
from app.utils.errors import AppError
from app.config import settings
from app.mcp import create_mcp_server

logger = logging.getLogger(__name__)


@asynccontextmanager
async def lifespan(app: FastAPI):
    """Manage application lifecycle."""
    logger.info("Market Data Hub starting up...")
    yield
    logger.info("Market Data Hub shutting down...")


# Create FastAPI application
app = FastAPI(
    title="Market Data Hub",
    description="Real-time market data aggregation from IBKR and LSEG",
    version="1.0.0",
    lifespan=lifespan
)

# Register routers
app.include_router(routes_meta.router, tags=["Meta"])
app.include_router(routes_prices.router, tags=["Prices"])
app.include_router(routes_companies.router, tags=["Companies"])
app.include_router(routes_options.router, tags=["Options"])
app.include_router(routes_ws.router, tags=["WebSocket"])


@app.exception_handler(AppError)
async def app_error_handler(request: Request, exc: AppError):
    """Handle application errors with proper HTTP status mapping."""
    status_code = {
        "DATA_NOT_FOUND": 404,
        "INVALID_PROVIDER": 400,
        "PROVIDER_TIMEOUT": 503,
        "PROVIDER_CONNECTION_ERROR": 503,
    }.get(exc.code, 500)

    return JSONResponse(
        status_code=status_code,
        content={"detail": exc.message, "code": exc.code, "details": exc.details}
    )


@app.exception_handler(Exception)
async def general_error_handler(request: Request, exc: Exception):
    """Handle unexpected errors."""
    logger.error(f"Unexpected error: {exc}", exc_info=True)
    return JSONResponse(
        status_code=500,
        content={"detail": "Internal server error"}
    )


def run_http_server(host: str = "0.0.0.0", port: int = 8000):
    """Run FastAPI HTTP server."""
    logger.info(f"Starting HTTP server on {host}:{port}")
    uvicorn.run(
        "app.main:app",
        host=host,
        port=port,
        reload=settings.app_env == "dev",
        log_level=settings.log_level.lower()
    )


def run_mcp_server():
    """Run MCP (Model Context Protocol) server with SSE transport."""
    logger.info("Starting MCP server with SSE transport on port 8001")
    mcp = create_mcp_server(app)
    mcp.run(transport="sse", port=8001)


def run_both_servers():
    """
    Run both HTTP and MCP servers in parallel.

    Note: This requires async task management or process forking.
    For production, use orchestration (Docker Compose, Kubernetes) instead.
    """
    import subprocess

    # Start HTTP server in background
    http_process = subprocess.Popen(
        [sys.executable, "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
    )

    # Start MCP server in foreground
    mcp = create_mcp_server(app)

    try:
        mcp.run(transport="sse", port=8001)
    except KeyboardInterrupt:
        logger.info("Shutting down servers...")
        http_process.terminate()
        http_process.wait()


if __name__ == "__main__":
    # Parse CLI arguments
    mode = "http"  # default

    if len(sys.argv) > 1:
        mode = sys.argv[1].lower()

    if mode == "http":
        run_http_server()
    elif mode == "mcp":
        run_mcp_server()
    elif mode == "both":
        run_both_servers()
    else:
        logger.error(f"Unknown mode: {mode}")
        logger.info("Usage: python app/main.py [http|mcp|both]")
        sys.exit(1)
```
