# Company News API Implementation Specification

**Feature Branch:** `feature/company-news`

## Objective
Implement a comprehensive company news API endpoint that fetches news articles from both IBKR and LSEG providers with flexible time-based filtering, pagination, language support, and CSV export capabilities.

## Core Requirements

### 1. Data Models (`app/models/news.py`)
Create new Pydantic models for news articles and responses:

```python
"""News article models."""

from datetime import datetime, date
from typing import List, Optional
from pydantic import BaseModel, Field


class NewsArticle(BaseModel):
    """Single news article."""
    article_id: str = Field(..., description="Format: {provider}:{native_id}")
    title: str
    summary: str
    published_at: datetime
    source: str
    url: str
    full_text: Optional[str] = Field(None, description="Full article text if available")
    category: Optional[str] = Field(None, description="Category: earnings, merger, product, legal, etc.")


class NewsMetadata(BaseModel):
    """Pagination and query metadata for news response."""
    total: int
    limit: int
    offset: int
    has_more: bool
    provider: str
    from_date: date
    to_date: date


class NewsResponse(BaseModel):
    """Standardized news response with pagination."""
    data: List[NewsArticle]
    meta: NewsMetadata
```

**Key Design Decisions:**
- `article_id` format: `{provider}:{native_id}` (e.g., "lseg:abc123", "ibkr:xyz789")
- `full_text` is optional - providers may not provide full article text
- `category` is optional - basic classification (earnings, merger, product, legal)
- Response wrapped with metadata for pagination context

### 3. LSEG News Provider Implementation (`app/providers/lseg.py`)
Extend `LSEGProvider` class with `BaseNewsProvider`:

```python
from app.models.news import NewsArticle
from datetime import date
import pandas as pd
import refinitiv.data as rd

class LSEGProvider(BaseCompanyProvider, BaseNewsProvider):
    """LSEG provider implementation."""

    async def get_company_news(
        self,
        symbol: str,
        from_date: date,
        to_date: date,
        limit: int = 20,
        offset: int = 0,
        language: str = "en",
        category: Optional[str] = None
    ) -> List[NewsArticle]:
        """Get news articles for a company from LSEG."""
        try:
            # 1. Convert ticker to RIC
            ric = self._ticker_to_ric(symbol)
            if not ric:
                raise DataNotFoundError("Ticker", symbol)

            # 2. Fetch news headlines using Refinitiv Data Library
            response = rd.news.headlines.Definition(
                query=f"R:{ric}",
                count=limit + offset,  # Fetch more for offset
                date_from=from_date.isoformat(),
                date_to=to_date.isoformat()
            ).get_data()

            # 3. Check response validity
            if not response or response.data.df is None or response.data.df.empty:
                return []

            df = response.data.df

            # 4. Apply offset and limit
            if offset > 0:
                df = df.iloc[offset:]
            df = df.head(limit)

            # 5. Parse articles from DataFrame
            articles = []
            for _, row in df.iterrows():
                # Extract basic fields
                article_id = f"lseg:{row.get('storyId', '')}"
                title = row.get('headline', 'No title')
                published_at = pd.to_datetime(row.get('versionCreated'))
                source = row.get('sourceCode', 'LSEG')
                url = row.get('storyUrl', '')

                # 6. Map LSEG subjects to categories
                subjects = row.get('subjects', [])
                category_map = {
                    'EARN': 'earnings',
                    'M&A': 'merger',
                    'PROD': 'product',
                    'REG': 'legal'
                }
                article_category = None
                if isinstance(subjects, list):
                    for subj in subjects:
                        if subj in category_map:
                            article_category = category_map[subj]
                            break

                # 7. Apply category filter
                if category and article_category != category:
                    continue

                # 8. Attempt to fetch full text (optional)
                full_text = None
                try:
                    story_response = rd.news.get_story(story_id=row.get('storyId'))
                    if story_response and story_response.data:
                        full_text = story_response.data.story
                except Exception:
                    pass  # Full text is optional

                # 9. Create article object
                articles.append(NewsArticle(
                    article_id=article_id,
                    title=title,
                    summary=row.get('firstParagraph', title),
                    published_at=published_at,
                    source=source,
                    url=url,
                    full_text=full_text,
                    category=article_category
                ))

            return articles

        except DataNotFoundError:
            raise
        except Exception as e:
            logger.error(f"LSEG news error for {symbol}: {e}")
            raise ProviderError(f"Failed to fetch news from LSEG: {str(e)}")
```

**LSEG-Specific Notes:**
- Uses `rd.news.headlines.Definition()` for news feed
- RIC conversion required (use existing `_ticker_to_ric()` method)
- May provide full text via `rd.news.get_story()`
- Subject codes map to categories (EARN, M&A, PROD, REG)
- Language support available in LSEG API

### 4. IBKR News Provider Implementation (`app/providers/ibkr.py`)
Extend `IBKRProvider` class with `BaseNewsProvider`:

```python
from app.models.news import NewsArticle
from datetime import date, datetime, timezone
from ib_insync import Stock

class IBKRProvider(BasePriceProvider, BaseOptionsProvider, BaseCompanyProvider, BaseNewsProvider):
    """IBKR provider implementation."""

    async def get_company_news(
        self,
        symbol: str,
        from_date: date,
        to_date: date,
        limit: int = 20,
        offset: int = 0,
        language: str = "en",
        category: Optional[str] = None
    ) -> List[NewsArticle]:
        """Get news articles for a company from IBKR."""
        await self._ensure_connection()

        try:
            # 1. Create and qualify contract
            contract = Stock(symbol, 'SMART', 'USD')
            qualified = await self.ib.qualifyContractsAsync(contract)
            if not qualified:
                raise DataNotFoundError("Contract", symbol)

            contract = qualified[0]

            # 2. Request historical news from IBKR
            news_items = await self.ib.reqHistoricalNewsAsync(
                conId=contract.conId,
                providerCodes='',  # All news providers
                startDateTime=f"{from_date.isoformat()} 00:00:00",
                endDateTime=f"{to_date.isoformat()} 23:59:59",
                totalResults=limit + offset
            )

            if not news_items:
                return []

            # 3. Apply offset and limit
            news_items = news_items[offset:offset + limit]

            # 4. Parse news items
            articles = []
            for item in news_items:
                article_id = f"ibkr:{item.articleId}"

                # Parse timestamp
                published_at = datetime.fromtimestamp(item.time, tz=timezone.utc)

                # 5. Detect category from headline (IBKR doesn't provide explicit categories)
                title_lower = item.headline.lower()
                article_category = None
                if 'earnings' in title_lower or 'profit' in title_lower or 'revenue' in title_lower:
                    article_category = 'earnings'
                elif 'merger' in title_lower or 'acquisition' in title_lower or 'buyout' in title_lower:
                    article_category = 'merger'
                elif 'product' in title_lower or 'launch' in title_lower or 'release' in title_lower:
                    article_category = 'product'
                elif 'lawsuit' in title_lower or 'regulation' in title_lower or 'sec' in title_lower:
                    article_category = 'legal'

                # 6. Apply category filter
                if category and article_category != category:
                    continue

                # 7. Create article object
                articles.append(NewsArticle(
                    article_id=article_id,
                    title=item.headline,
                    summary=item.headline,  # IBKR doesn't provide separate summary
                    published_at=published_at,
                    source=item.providerCode,
                    url='',  # IBKR doesn't provide direct URLs
                    full_text=None,  # Not available in historical news
                    category=article_category
                ))

            return articles

        except DataNotFoundError:
            raise
        except Exception as e:
            logger.error(f"IBKR news error for {symbol}: {e}")
            raise ProviderError(f"Failed to fetch news from IBKR: {str(e)}")
```

**IBKR-Specific Notes:**
- Uses `reqHistoricalNewsAsync()` with contract ID
- Requires contract qualification first
- No separate summary field (use headline)
- No direct URLs provided
- Category detection via keyword matching in headline
- Language parameter not directly supported by IBKR API

### 5. API Endpoint (`app/api/routes_companies.py`)
Add news endpoint to company routes:

```python
from app.models.news import NewsArticle, NewsResponse, NewsMetadata
from datetime import date, timedelta
from fastapi import Query
from fastapi.responses import StreamingResponse
from app.utils.csv_export import to_csv
from app.dependencies import get_news_provider
import io

@router.get("/companies/{symbol}/news", response_model=NewsResponse)
async def get_company_news(
    symbol: str,
    provider: str = Query("lseg", description="Data provider (lseg, ibkr)"),
    days: Optional[int] = Query(None, description="Last N days (overrides from/to dates)"),
    from_date: Optional[date] = Query(None, description="Start date (YYYY-MM-DD)"),
    to_date: Optional[date] = Query(None, description="End date (YYYY-MM-DD)"),
    limit: int = Query(20, ge=1, le=100, description="Results per page (max 100)"),
    offset: int = Query(0, ge=0, description="Pagination offset"),
    language: str = Query("en", description="Language code (ISO 639-1: en, de, fr, etc.)"),
    category: Optional[str] = Query(None, description="Filter by category (earnings, merger, product, legal)"),
    format: str = Query("json", description="Response format (json, csv)")
):
    """
    Get news articles for a company.

    **Time Range Priority:**
    1. If `days` is provided: Last N days from today (overrides from/to)
    2. If `from_date` and/or `to_date` provided: Use explicit range
    3. Default: Last 30 days

    **Examples:**
    - Last 7 days: `?days=7`
    - Last 30 days (default): `/companies/AAPL/news`
    - Specific range: `?from_date=2026-01-01&to_date=2026-01-04`
    - Earnings only: `?category=earnings`
    - CSV export: `?format=csv`
    - German news: `?language=de`
    - Pagination: `?limit=50&offset=50`
    - IBKR provider: `?provider=ibkr`
    """
    # 1. Determine date range (priority: days > explicit dates > default)
    if days:
        to_date_calc = date.today()
        from_date_calc = to_date_calc - timedelta(days=days)
    elif from_date or to_date:
        from_date_calc = from_date or (date.today() - timedelta(days=30))
        to_date_calc = to_date or date.today()
    else:
        # Default: last 30 days
        to_date_calc = date.today()
        from_date_calc = to_date_calc - timedelta(days=30)

    # 2. Get provider instance (raises HTTPException if invalid)
    news_provider = get_news_provider(provider)

    # 3. Fetch news articles
    articles = await news_provider.get_company_news(
        symbol=symbol,
        from_date=from_date_calc,
        to_date=to_date_calc,
        limit=limit,
        offset=offset,
        language=language,
        category=category
    )

    # 4. Calculate metadata
    total = len(articles) + offset  # Simplified - actual total unknown without full scan
    has_more = len(articles) == limit  # If we got exactly limit, there may be more

    # 5. CSV export if requested
    if format.lower() == "csv":
        content_type, csv_bytes = to_csv(articles, filename=f"{symbol}_news.csv")
        return StreamingResponse(
            io.BytesIO(csv_bytes),
            media_type=content_type,
            headers={
                "Content-Disposition": f"attachment; filename={symbol}_news.csv"
            }
        )

    # 6. Return JSON response
    return NewsResponse(
        data=articles,
        meta=NewsMetadata(
            total=total,
            limit=limit,
            offset=offset,
            has_more=has_more,
            provider=provider,
            from_date=from_date_calc,
            to_date=to_date_calc
        )
    )
```

**API Design Notes:**
- Default provider: LSEG (more comprehensive news)
- Default time range: Last 30 days
- Sorting: Always newest first (no sort parameter - fixed behavior)
- Error handling: Fail immediately if provider unavailable (no fallback)
- CSV export: Uses existing `app/utils/csv_export.py` utility
- Query parameter validation via Pydantic

## Notes & Considerations

### Provider Differences
| Feature | LSEG | IBKR |
|---------|------|------|
| Full Text | Sometimes available | Not available |
| URL | Direct article link | Not provided |
| Summary | Separate field | Same as headline |

### Limitations
- **IBKR**: Limited to headline-based category detection (not precise)
- **LSEG**: Full text requires additional API call (may be slow)
- **Total Count**: Not accurately known without full scan (simplified as `len + offset`)
- **Sorting**: Fixed to newest first (no customization)
